# TITANS ARENA

Plataforma de torneos de eFootball para la comunidad TITANS.

## Arrancar en tu Mac

```bash
cd titans-arena
npm install
npm run dev
```

Abre: http://localhost:3000

## Demo

- Admin: shadow@titans.gg o admin (cualquier contraseña)
- Logo: public/logo-titans.jpg

## WhatsApp comunidad

Cambia el link real en src/lib/whatsapp.ts (WHATSAPP_COMMUNITY_URL)

## Incluye

Login, Registro con WhatsApp, Perfil, Ranking, Torneos, Admin con fotos,
boton Comunidad, contactar rival por WhatsApp, Calendario, Campeones.
